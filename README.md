# csharp-masterclass 🎓

My hands-on journey through learning C# — from `Hello, World!` up to classes, LINQ, dictionaries, WPF desktop apps, and SQL databases. This repo is a personal learning log: real projects I built, notes I took, exercises I solved, and the course's starter/solution snapshots.

## What's inside ♪

| Folder | What it is |
|--------|------------|
| `HelloWorld/` | First .NET console app — the classic "Hello, World!" |
| `MyConsoleApp/` | Second console app, building on the basics |
| `WPFDemo/` | WPF demo project with data binding and list box windows |
| `CurrencyConverter_Static/` | WPF Currency Converter desktop app (static exchange-rate data) |
| `Course content/` | 60 notes & cheatsheets (`.md`) across 14 sections — syntax, classes, OOP, collections, error handling, inheritance, interfaces, structs, events & delegates, regular expressions, databases, and WPF |
| `exercises-code/` | 2 coding exercises with prompts + solutions to practice each concept |
| `quizzes/` | Knowledge-check quizzes |
| `course-zips/` | 116 course starter/solution project snapshots, organized by lesson |

## Projects

All projects are standard .NET console or WPF apps.

```bash
# run a console project
cd HelloWorld
dotnet run

# run the WPF Currency Converter (requires WPF runtime / Windows)
cd CurrencyConverter_Static
dotnet run
```

- **`HelloWorld`** — first .NET console app.
- **`MyConsoleApp`** — second console app, building on the basics.
- **`WPFDemo`** — WPF desktop project demonstrating data binding and list box windows.
- **`CurrencyConverter_Static`** — a WPF currency converter that converts between currencies using static exchange-rate data. Tutorial source: [tutorials.eu — Build a Currency Converter Application Using WPF in C# with Static Data](https://tutorials.eu/build-a-currency-converter-application-using-wpf-in-c-with-static-data/).
