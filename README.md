# csharp-masterclass 🎓

My hands-on journey through learning C# — from `Hello, World!` up to classes, LINQ, and dictionaries. This repo is a personal learning log: real projects I built, notes I took, exercises I solved, and the course's starter/solution snapshots.

## What's inside ♪

| Folder | What it is |
|--------|------------|
| `HelloWorld/` | First .NET console app — the classic "Hello, World!" |
| `MyConsoleApp/` | Second console app, building on the basics |
| `docs/` | 38 notes & cheatsheets (`.md` + `.webp`) covering syntax, classes, methods, recursion, and more |
| `exercises/` | 16 coding exercises with prompts to practice each concept |
| `quizzes/` | Knowledge-check quizzes |
| `course-zips/` | 76 course starter/solution project snapshots, organized by lesson |

## Projects

Both `HelloWorld` and `MyConsoleApp` are standard .NET console apps targeting `net10.0`.

```bash
# run either project
cd HelloWorld
dotnet run
```

## Notes

- `course-zips/` contains the downloaded course material. Each zip is a distinct lesson checkpoint — kept for reference, not edited.
- Build artifacts (`bin/`, `obj/`) are git-ignored.
