## Initializing a List with Items

Exercise: Initializing a List with Items

INSTRUCTIONS:

Your task is to create a C# program that:

1. Declares a List of integers inside the PrintNumbers method.

2. Initializes the list with the values 1, 2, and 3.

3. Uses a foreach loop to print each number followed by a space.

Important Notes:

- To avoid compatibility issues, use this syntax:
```csharp
List<int> myNumbers = new List<int> { 1, 2, 3 };
```
Do not use List<int> myNumbers = [1, 2, 3];, as it may not work in all environments.

The expected output is:
```markdown
1 2 3 
```
(Each number followed by a space, no newline at the end).



✅ Do not modify the existing method signature or class structure.
✅ Keep your solution simple and to the point.



💡 Hint: The foreach loop is ideal for iterating over lists in C#.
