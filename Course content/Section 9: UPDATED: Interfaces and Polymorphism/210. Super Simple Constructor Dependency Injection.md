### Dependency Injection (DI)

**What is Dependency Injection?**

Dependency injection is a programming techique that **makes a class independent of its dependencies.**

This **help you to follow SOLID**'s dependency inversion and single responsility principles.

**Type of D.I.**

**Constructor Injection:**

Depenencies are **provied through a class constructor**, ensuing that the class **receives all tis dependencies at the time of instantiation.**
```csharp
public class MyClass {
    private readonly IDependency _dependency;
    public MyClass(IDependency dependency) {
        _dependency = dependency;
    }
}
```
