### What is an Interface?

An interface in C# is like a **blueprintg that defines methods and properies a class must have, but it doesn't provide the actual code** for them. It's used to ensure different classes follow the same rules.

### Why use an Interface?

**1. Abstraction:**

Defines **what methods** a class should implement **wuthout specifyhing how.**

Interfaces tell classes what they need to do, but not how to do it.

**2. Polymorphism:**

Allows **different classes to be treated as instances** of the iterface type.

Interfaces let different classes be used in the same way.

**3. Decoupling:**

**Reduces dependencies between classes*, making the code more modular and easier to maintain.

Interfaces help keep classes separate so the code is easier to manage and update.

**4. Reusablility:**

Ensures that **different classes can use common methods**, enhancing code reusability.

Interfaces make it easy to reuse code across different classes.

**5. Testability:**

**Facilitates unit testing by allowing mock implementations of interfaces.

Inferfaces make testing easier by allowing fake versions of classes for testing purposes.
