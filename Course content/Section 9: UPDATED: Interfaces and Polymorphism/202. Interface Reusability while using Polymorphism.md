### Why Polymorphic Interfaces?

**1. Where:**

When you need **different classes to implement the same set of methods** or properies. This ensures consistency and allows for flexible implementations.

**2. Why:**

Promotes **code reusablility and flexibility.** Different classes can implement the smae interface in various ways, allowing for divers behavior while maintaining a common contract.

**3. When:**

User interfacees when you have **multiple classes that should provider the same functionality** but might implement it differently. Real-World **Example: Payment Processing System

```csharp
namespace InterfaceApp;

public interface IPaymentProcesser
{
    void ProcessPayment(decimal amount);
}

public class CreditCardProcessor: IPaymentProcesser
{
    public void ProcessPayment(decimal amount)
    {
        Console.WriteLine($"Processing credit card payment of {amount}");
        //Implement credit card payment logic.
    }
}

public class PaypalProcessor: IPaymentProcesser
{
    public void ProcessPayment(decimal amount)
    {
        Console.WriteLine($"Processing paypal payment of {amount}");
        //Implement paypal playment logic.
    }
}

public class PaymentService
{
    private readonly IPaymentProcessor _procesor;

    publice PaymentService( IPaymentProcesor processor )
    {
        _processor = processor
    }

    public void ProcessOrderPayment(decomal amount)
    {
        _processor.ProcessPayment(amount);
    }
}

internal class Program
{
    static void Main(string[] args)
    {
        // Polymorphism
        IPaymentProcessor creditCardProcessor = new CreditCardProcessor();
        PaymentService paymentService = new PaymentService( creditCardProcessor );
        paymentService.ProcessOrderPayment(100.00m)

        IPaymentProcessor paypalProcessor = new PaypalProcessor();
        PaymentService paymentService = new PaymentService( paypalProcessor );
        paymentService.ProcessOrderPayment(200.00m)

        Console.ReadKey();
    }
}
```
