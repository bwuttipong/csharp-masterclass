### What are Structs?

- Structs (short for "structures"") in C#, structs are value types that are typcally used to encapsulate small groups of related variable

- Structs are best used for small data structures that have value semantics and will not be modified after creation. Examples include complext numbers, points in a coordinate system, and RGB colors, If you need inheritance, polymorphism, or large data structires, classes are typically more appropriate.

Structs are similar t oclasses but have some importanct differnces.

### Key Differences Structs and Clases

- Value Type: Structs are value types, which means they are stored on the stack (or inline in containing types) and not on the heap. This generally makes them more efficient in terms of memory allocation reference types and stored on the heap.
