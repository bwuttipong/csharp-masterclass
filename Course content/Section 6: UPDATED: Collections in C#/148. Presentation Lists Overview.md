# Lists in C#

## What is a List<T>?

A **List<T>** is a generic collection that stores elements in a linear sequence. Unlike arrays, lists are dynamic, which means their size can increase or decrease as needed.

## What is this T?

The "T" in List<T> in C# is a placeholder for a type. You can think of it like a black space in a sentence that can fill in with any type (like, int, string, or even a class you create like Car). This allows you to create a list specifically for that type of item.

List<int> numbers = new List<int>(); // This is like saying "Here's a box for holding numbers."
numbers.Add(1); // Add the nunmber 1 to the box.
numbers.Add(2); // Add the number 2 to the box.

List<string> numbers = new List<string>(); // This is like saying "Here's a box for holding names."
numbers.Add("Alice"); // Add "Alice" to the box.
numbers.Add("Bob"); // Add "Bob" to the box.

Using "T" makes the list versatile because you can define what type of items it should hold each time you use it, just like how you can decide what to put in a box each time you get a new box.

## Properties of Lists

- Count: Gets the number of elements contained in the list.

- Capacity: Gets or sets the number of elements that the list can hold before needing to resize.

## Core Method of Lists

- **Add(T item):** Adds an item to the end of the list.
- **Remove(T itme):** Removes the first occurrence of a specific object form the list.
- **Insert(int index, T item):** Inserts an element at the specified index. 
- **Find(Predicate<T> match):** Searches for an element that matches the conditions defined by a specified predicate.
- **Sort():** Sorts the elements in the entire List<T>.
- **Clear():** Removes all elements from the list.
- **ToArray():** Copies the elements of the List<T> to a new array.
- **IndexOf(T item):** Returns the index of the first occurrence of a specific object in the list.

## Lists vs Arrays Size Flexibility

- Arrays are fixed-size, meaning once you define the number of elements it can hold, it cannot be resized without creating a new array.
- List<T>, on the other hand, can adjust its size dynamically.

## Performance

- Arrays offer slightly faster performance of indexing and iteration becasue they are simpler and have direct access to their memory locations.
- Lists, while also very efficient, have a slight overhead due to dynamic resizing and other additional features.


## Functionality

- Arrays provide a straightforward data structure for storing and accessing fixed numbers of elements.
- Lists come with many more built-in methods for searching, sorting, and manipulating data.

## Ease of Use

- Arrays are preferable when the number of elements is known in advance and does not change.
- Lists are generally easier to use when you need to add or remove items frequently.
