### Events in C#?

**What is an Event?**

An event let's **one class tell others when somthing important happends.**
It uses a special method called a **delegate.**

This means one part of the program can
alert others without needing direct connections.

**Where would we use an Event?**

Events are common in **loggin, monitoring, data chagnes, and button clicks.**
They are used **wherever notifications are needed.**

Any situation where one action triggers
other responses can benefit from events.
