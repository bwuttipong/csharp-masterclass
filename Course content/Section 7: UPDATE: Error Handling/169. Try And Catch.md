# TRY/CATCH

### Purpose:
Try/Catch blocks are used to handle exceptions and errors in a controlled way.

- **try:** The block of code where exceptions might occur.

- **catch:** The block of code that handles the exception. You can catch speciic exceptions or a general exception.

- **finally:** (Optional) This block will execute whether or not an exception was thrown.
**We will learn more about the "Finally" Keyword in the next lecture.**
