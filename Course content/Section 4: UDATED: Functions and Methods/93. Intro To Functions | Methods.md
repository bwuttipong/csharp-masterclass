# Methods in C#

## Method

- A method is a code block that contains a series of statements. A program causes the statements to be executed by calling the method and specifying any required method argeuments. In C#, every executed instruction is performed in the context of a method. The Main method is the entry point for every C# application and it is called by the commond language runtime (CLR) when the program is started.

## Syntax

```Text
<Access Specifier> <Return Type> <Method Name> (Parameter List)
{
    Mothod Body
}
```

### What are those things?

- Access Specifier — The Access Specifier determines he visiblity of a varaible or a method from another class.

- Return type — A method may return a value. The return type is the data type of the value the method returns. If the method is not rreturning any values, then the return type is void.

- Method name — Method name is a unique identifier and it is case sensitive. It cannot be samea as any other identifier decalred in the class.

- Parameter list — Enclosed between parentheses, the parameters are used to pass and receive data from a method. The parameter list refers to the type, order, and number of the parameters of a method, Parameters are optional; that is, a method may contain no parameters.

- Method body — This contains the set of instructions needed to complete the required activity.
